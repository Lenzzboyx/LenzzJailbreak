◇ JAILBREAK CENTER — PANDUAN & DOKUMENTASI
1. DEFINISI JAILBREAK

Jailbreak dalam konteks LLM adalah teknik untuk melewati batasan yang diterapkan pada model AI, baik berupa safety filter, alignment training, maupun instruction hierarchy.

Tujuan dokumentasi: riset keamanan, red team, dan pemahaman teknis tentang pengujian serta penguatan model.

2. KLASIFIKASI TEKNIK

Roleplay / Persona — Medium — Persona Detection
Encoding — Low/Medium — Input Decoding
Fragmentation — Medium — Context Tracking
Meta-Prompt — Instruction hierarchy testing
Language Switch — Multilingual filter testing
Token Smuggling — Unicode / Homoglyph normalization
Payload Split — Semantic analysis
Crescendo — Gradual escalation / intent tracking

3. ANATOMI PROMPT JAILBREAK

[1] PREFACE — konteks baru
[2] AUTHORITY CLAIM — klaim izin
[3] REFRAME — ubah tujuan
[4] INSTRUCTION — payload utama
[5] LOCK — uji konsistensi/backout

4. CONTOH TEKNIK KLASIK

DAN, Developer Mode, Grandma Exploit, dan Hypothetical Scenario dapat dipakai sebagai kategori pengujian defensif.

5. TEKNIK ENCODING

Base64, ROT13, Hex, Leetspeak, dan Homoglyph dapat digunakan sebagai transformasi input untuk menguji decoding dan normalisasi.

6. MULTI-TURN ATTACK (CRESCENDO)

Fase 1 — Rapport Building
Fase 2 — Academic Framing
Fase 3 — Specific Probe
Fase 4 — Payload Delivery

7. DEFENSE MECHANISM

Input Filter → Intent Classifier → Constitutional/Safety Check → Output Filter → Sandbox.
Tambahkan rate limit, multi-turn tracking, adversarial training, logging, dan disclosure.

8. FRAMEWORK RED TEAM

Uji hanya model/endpoint yang kamu miliki izin. Dokumentasikan scope, reproduksi, dampak, dan mitigasi.

9. SCRIPT SCANNER RED TEAM

Gunakan scanner pada endpoint sendiri atau yang memiliki izin. Hindari pengujian layanan publik tanpa izin.

10. ETIKA & LEGAL RED TEAM

DO: test dengan izin, dokumentasi, scope terbatas, sandbox, dan laporkan vulnerability melalui channel resmi.
DON'T: menguji model publik tanpa izin, mendistribusikan payload bypass tanpa konteks, mengeksploitasi data orang lain, atau membuat konten ilegal.

11. REFERENSI AKADEMIK

12. CHEATSHEET RINGKAS

Attack vectors: Roleplay, Encoding, Fragmentation, Language Switching, Multi-turn, Hypothetical framing, Authority claim, Token smuggling.

Defense: Input → Intent → Constitutional → Output → Sandbox.
